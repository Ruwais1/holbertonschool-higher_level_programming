# Higher Level Programming - JavaScript

This repository contains JavaScript projects focused on programming fundamentals and dynamic web interaction.

## 📂 Projects

* **`javascript-warm_up`**: Basics of JavaScript (variables, loops, arrays, functions, and objects) executed via Node.js.
* **`javascript-dom_manipulation`**: Interacting with HTML pages using the DOM API, handling events, and fetching external data.

## 🛠️ Tech Stack
* JavaScript (ES6)
* Node.js
* DOM API & Fetch API
