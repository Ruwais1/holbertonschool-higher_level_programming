# 🐍 Python - Everything is object

## 📝 Description
This project dives deep into the inner workings of Python, exploring how the language handles objects, variables, and memory management. It focuses on the crucial differences between mutable and immutable objects, references, assignments, and aliasing. Understanding these concepts is essential for writing efficient Python code and avoiding unexpected bugs.

## 🎯 Learning Objectives
By completing this project, you will understand:
* What an object is in Python.
* The difference between a class and an object or instance.
* The difference between **immutable** and **mutable** objects.
* What a reference, an assignment, and an alias are.
* How to determine if two variables are identical (using `is`).
* How to determine if two variables have the same value (using `==`).
* How to display a variable's memory address identifier (using `id()`).
* What the built-in mutable types (e.g., `list`, `dict`, `set`) and immutable types (e.g., `int`, `float`, `str`, `tuple`) are.
* How Python passes variables to functions (Call by Object Reference).

## 🛠️ Environment & Requirements
* **OS:** Ubuntu 20.04 LTS
* **Language:** Python 3.8.5
* **Style Guidelines:** PEP 8 / pycodestyle (version 2.7.*)
* **File Execution:** All `.py` files must be executable and start with `#!/usr/bin/python3`.
* **Answers Format:** `.txt` files must contain exactly one line with the answer, no spaces before or after, and no shebang line.

## 📂 Project Structure
This directory contains a mix of `.txt` files answering conceptual questions about Python's behavior, and `.py` scripts demonstrating specific object manipulations.
